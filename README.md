# Trendora storefront

An editorial luxury accessories storefront built with Astro 7, TypeScript, GSAP and custom responsive CSS.

## Requirements
- Node.js 22.23.4 or newer
- npm 10+

## Getting started
```bash
npm install
npm run dev
```

## Production
```bash
npm run check
npm run build
npm run preview
```

## Notes
- Product imagery is loaded from Unsplash.
- Newsletter feedback is front-end only; connect a mailing-list provider before collecting subscriptions.
- Search, wishlist and bag are presentation interactions and are not connected to a commerce backend.
- See [DESIGN.md](./DESIGN.md) for the visual system and interaction intent.
